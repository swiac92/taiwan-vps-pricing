## 固定IP VPS到底固定的是什么

固定IP VPS指的是分配了一个不变公网IP的云服务器：只要在续费期内，每次连接都是同一个地址。它和动态IP的区别就在这一点——动态IP可以手动或定时更换，适合轮换场景；静态IP稳定不变，适合一切依赖“登录状态”和“信任积累”的业务。

为什么这件事现在变得值钱了？平台风控判断一个IP靠不靠谱，主要看三样东西：ASN（自治系统编号）、地理归属、ISP归属。机房IP段在这些检测面前天然吃亏，2024年以来各家防护系统（Cloudflare、Datadome、Akamai，以及TikTok、亚马逊等平台自建的风控）普遍把机房ASN默认当成可疑来源。一个几年前跑得好好的便宜机房VPS，现在登录电商平台后台可能几小时内就撞上验证码。

“原生IP”是另一个容易混的概念。它指IP资源本身就注册在台湾本地ISP名下；从其他地区广播过来的IP，可能在ASN、地理或ISP归属的某一项上露馅。台湾原生IP段供应量本来就少，能稳定提供全新IP段的服务商更不多，这是这个品类价格下不来的根本原因。

顺带说说不适合的人：如果用途是挂博客、跑CI、部署企业官网，入站流量并不吃IP信任度，普通机房VPS更划算，没必要为IP属性多花钱。

## 问一句IP段怎么来的，能避开不少坑

同样是固定IP VPS，不同服务商的IP来源差别很大，市面上常见三种做法：一是双ISP架构，机房同时接普通运营商和住宅ISP两条线路，管理流量走前者、客户出站走后者，IP真实归属消费级ASN；二是买断原本属于ISP的IP段再广播出去；三是隧道出口，虚拟机本体在普通机房，出站流量通过隧道从住宅端点出去。前两种对外表现基本一致，第三种一旦隧道断线IP就会变，故障模式多。
